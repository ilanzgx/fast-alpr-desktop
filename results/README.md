# Resultados e Métricas de Avaliação

Este diretório armazena os relatórios de avaliação, matrizes de confusão e métricas consolidadas dos experimentos.

## Arquivos Gerados

- `metricas.csv`: Tabela consolidada dos experimentos EXP-01 a EXP-07 comparando métodos clássico vs YOLO, motores de OCR e impacto dos pré/pós-processamentos.
- `catalogo_falhas.csv`: Registro estruturado de casos onde o sistema falhou, com causa provável e proposta de mitigação.
